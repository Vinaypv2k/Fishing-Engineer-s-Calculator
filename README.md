## Standards
The application deliberately labels several calculations as screening/estimators. API's current standards pages identify API Spec 5CT 11th Edition for casing/tubing and list RP 5C3 under development as Edition 8 (standards plan dated 2026-02-18). TR 5C3 covers performance properties including axial strength, internal pressure resistance and collapse resistance. Production use should implement the exact licensed edition/addenda/errata adopted by the operator and actual OEM/API product data.
